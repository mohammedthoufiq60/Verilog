\# Verilog HDL



This repository contains my Verilog HDL learning journey.



The goal of this repository is to strengthen my understanding of digital logic, RTL design, and FPGA development by implementing Verilog modules, writing testbenches, and verifying their functionality through simulation.



The designs are developed and verified by me while learning Verilog and FPGA design.
